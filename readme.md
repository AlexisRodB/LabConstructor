Que ventaja tecnica tiene crear un molde (funcion constructora) en lugar de escribir un objeto literal estructurado individualmente para cada computador? EJERCICIO1

R//: La ventaja de usar un molde es que evita repetir codigo al definir la estructura una sola vez, garantiza que todos los computadores tengan exactamente los mismos datos y permite crear muchos objetos de forma rapida y ordenada sin escribirlos a mano.

Por qué un método interno puede acceder de manera precisa y aislada a las propiedades específicas de su propio objeto utilizando la palabra clave this? EJERCICIO2

R//: La palabra clave this apunta específicamente al objeto que se está ejecutando en ese momento, lo que permite que el método consulte y use únicamente las propiedades de ese objeto en particular sin mezclarlas con las de otros.

¿Qué ventajas a nivel de cohesión de software presenta el hecho de que el objeto conozca por sí mismo su estado lógico (si aprobó o no)? EJERCICIO3

R//: Permite que toda la información y la lógica de validación residan dentro del mismo objeto, evitando que funciones externas tengan que calcular o adivinar su estado, lo que hace que el código sea más independiente, ordenado y fácil de mantener.

¿Qué ventajas tiene permitir que la información sea ingresada por el usuario en lugar de escribir los datos directamente en el código? EJERCICIO5

R//: Permite que el software sea interactivo y dinámico, adaptándose a datos reales proporcionados por el usuario en tiempo de ejecución sin necesidad de modificar el código fuente cada vez que se quiera registrar un vehículo nuevo.
